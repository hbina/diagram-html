Supported syntax & limits

A custom flowchart parser, supporting a subset of Mermaid syntax. No Mermaid library is used.

flowchart LR or graph TB; directions LR, RL, TB, TD, BT. Nodes: a[Label], a("Label"), a{Decision}, or bare IDs. Edges: a --> b, a -->|label| b, a --- b, a -. select .-> b, a -.->|label| b, a -.- b; chains are accepted. Separate statements with newlines or semicolons. IDs use letters, numbers, underscores or hyphens.

%% comments and a leading YAML header with maxEdges / maxTextSize are accepted. Other header entries are ignored. Labels are plain text; quoted labels can contain punctuation. Node labels support <br/> line breaks. Subgraphs, styling directives and other diagram types are unsupported and report errors.

Defaults: 20,000 edges, 1,000,000 source characters. Layout uses layers, including cycle grouping. Dense graphs may have overlapping edges; rendering time depends on graph size and your device. Text stays in your browser. Nothing is sent or stored automatically.
